# Ремонт ноутбуков — Ленремонт

Статический сайт на Astro для услуги ремонта ноутбуков. Главная страница, страницы услуг и материалы для работы над дизайном находятся в `src/pages`.

## Запуск

Нужны Node.js `^22.12.0` или `^24.0.0`, npm версии 10 или новее и Git LFS для видео.

```sh
git lfs install
git lfs pull
npm ci
npm run dev
```

Адрес локального сервера появится в терминале. Подробнее о видео и Git LFS — в [docs/GIT_LFS.md](docs/GIT_LFS.md).

## Команды

- `npm run dev` — локальный сервер разработки.
- `npm run build` — статическая сборка в `dist/`.
- `npm run preview` — просмотр собранного сайта.
- `npm run check` — проверка Astro и TypeScript.
- `npm run format:check` — проверка форматирования.
- `npm run quality` — проверки и сборка; выполняйте перед передачей изменений.

## Структура

- `src/pages/` — маршруты сайта.
- `src/components/` и `src/layouts/` — компоненты и шаблоны страниц.
- `src/data/` — данные страниц.
- `src/styles/` — SCSS; `src/scripts/landing.js` подключает поведение сайта.
- `public/media/` — медиафайлы проекта.
- `docs/` — проектная документация; `artifacts/` — подготовленные материалы и результаты проверок.

Правила разработки и ограничения проекта описаны в [AGENTS.md](AGENTS.md). Перед существенной работой над лендингом прочитайте [мастер-промпт](docs/MASTER_DEVELOPMENT_PROMPT.md).
