Версия 1.0 · 9 октября 2026 года.

Самостоятельный комплект для реализации. Предыдущая переписка не нужна. Пользователь запросил полноценную страницу с продающими текстами и подготовку документов; реализация начнётся отдельным запросом в другом чате. Исходники сайта на этом этапе не меняются.

## Репозиторий

Папка: D:/works/projects/lr-remont-noutbykov.

База создана через npx @lenremont/landing-kit@latest create .; kit 0.3.1. Сейчас Astro 7.3.8, SCSS, vanilla JavaScript. Node ^22.12.0 либо ^24.0.0. Фактические версии читать в package.json и package-lock.json.

Уже есть StarterScreen.astro, LeadModal.astro, LeadCapture.astro, SocialLinks.astro и QR-коды мессенджеров. Стартовый экран и квиз — техническая основа, а не дизайн новой услуги. Не запускать генератор повторно в заполненной папке.

## Правила передачи

- Последнее прямое указание пользователя имеет высший приоритет.
- Этот комплект уточняет содержание и дизайн; технические правила AGENTS.md сохраняются.
- Документ 04 содержит публичный текст. Служебные пояснения из остальных файлов на сайт не выводятся.
- Выбрано одно направление. Не предлагать заново несколько концепций и не менять структуру ради удобства вёрстки.
- Не сочинять отзывы, рейтинги, имена инженеров, сроки заказов и другие бизнес-факты.
- Не добавлять таймеры, акции, рассрочку, регистрацию и другие услуги.
- Не публиковать сайт и не выполнять WordPress-экспорт без отдельного запроса.

## Перенос проекта

Открыть новый чат в этой же папке — достаточно. Для другой машины передать репозиторий с src, public, docs, конфигурацией, package.json, package-lock.json и AGENTS.md. node_modules, .astro и dist переносить не требуется.
