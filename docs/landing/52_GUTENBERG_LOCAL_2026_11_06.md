MP4 упаковывает локальная копия `artifacts/gutenberg-2026-11-06/compat/project-package.py`; обычный упаковщик 0.31.0 этот ресурс ещё не поддерживает.

Для редактора подготовлен отдельный `editor.css` с `data-lr-original-id`; display реальных контейнеров сохраняется. Лента брендов получила `position: relative` для корректного reduced motion.
