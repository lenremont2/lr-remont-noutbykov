# Штатный импортёр и WebM — 6 ноября 2026

По требованию владельца проект использует исходный импортёр **0.31.0 без изменений**. Локальная тестовая копия 0.31.3 заменена исходными 58 файлами из резервной копии. Центральный репозиторий плагина, установленный скилл и основной сайт не менялись. Прежние ZIP с зависимостью от `laptop-test` не использовать для переноса.

## Что изменено в проекте

- CSS, JS, шрифты, SVG и изображения остаются ресурсами страниц ZIP v4. В плагин ничего из проекта не добавляется.
- Видео сериализуется штатным `core/video`. Отдельный архив переносит три WebM в `wp-content/uploads/lr-remont-noutbykov/`: этот тип файлов отсутствует в ресурсном контракте импортёра.
- Варианты выбора хранятся редактируемыми текстовыми блоками внутри контейнеров. JS страницы создаёт из них нативные `select`, сохраняя значения, подписи, выбор, disabled, required и служебные атрибуты самих `option`, включая адрес мастерской. Настройки поведения сериализуются через уже поддерживаемый `data-ui`; исполняемой разметки в этих настройках нет. Код находится в `scripts/gutenberg/page-controls.js` и принадлежит странице.
- В холсте используются классы страницы, без изменения редакторского кода плагина. Вырезы SVG задаются CSS; подписи схем вынесены из SVG в редактируемый текст. Размеры Hero: SVG 18×18 px, контейнер 24×24 px.
- Старый генератор тестового плагина исключён из `scripts/gutenberg`; историческая копия сохранена только в игнорируемых артефактах.

## Видео

VP9, CRF 40; сохранены исходные разрешение и частота 24000/1001 fps. Исходные MP4 сохранены. Неиспользуемые немые аудиопотоки исключены: проверка исходного ролика показала максимум −91 dB.

## Проверки

Обычный упаковщик из установленного скилла принял пакет: 50 страниц, 124 изображения, 110 ресурсов. Все страницы сериализованы штатным Gutenberg 0.31.0 без монолитного HTML; при сборке проверены восстановление полей/вариантов и повторная инициализация без дублирования. Главная страница прошла локальную проверку WebM, форм, Hero на 1440/375 px и редактора. `npm run quality` и 37 Node-тестов прошли.

Повторно прошли 15 сценариев форм/квиза на 1440/375 px, включая выбор мастерской по карте, адресные варианты, ошибку 503, повтор и защиту от дублей. Все 16 POST остались на локальном сервере. Тестовый приёмник не входит в архивы. Первоначальная проверка выявила потерю `data-lr-workshop-address` у `option`; экспорт исправлен, а проверка всех атрибутов каждого варианта добавлена в сборку. Финальная сборка после исправления прошла сохранение и повторное открытие всех 50 редакторов без невалидных блоков: 150 состояний на 1440/1024/375 px, 200 иконок Hero. SEO, URL, авторы, статусы и родители сохранены; предыдущие 289 страниц не изменились. Ценовые подписи сохранили исходные 20 px и цвет после преобразования `b` в поддерживаемый `strong`.
