# Сгенерированные изображения неисправностей ноутбуков

Созданы 12 октября 2026 года встроенным инструментом imagegen. Девять отдельных изображений, единая серия. Финальные изображения: public/media/failure-*.webp, 768 × 512 px, WebP quality 84. Исходные PNG сохранены инструментом в каталоге Codex generated_images.

## Общая часть промпта

Use case: photorealistic-natural. Asset type: square thumbnail for a Russian laptop repair landing page, displayed at 160px. Create one original professional editorial photograph, square composition, centered close-up, main subject fully within the central 75 percent for a circular CSS crop. Same visual series: charcoal grey unbranded laptop, light warm grey repair bench, muted graphite and beige palette, soft diffused studio daylight, realistic materials and technically plausible details, crisp focal subject, restrained background, no people or faces unless hands needed. No text, no logos, no lettering, no watermarks, no collages, no flames.
