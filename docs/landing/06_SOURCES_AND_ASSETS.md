## 3. Решение по ценам

На S1 одновременно присутствуют старые промоблоки с низкими ценами и раздел «Прайс на ремонт ноутбуков» с детальным перечнем. В документ 04 перенесены числовые значения подробного прайса. Формулировки работ сокращены для чтения без изменения услуги.

Для стандартных ноутбуков: охлаждение 2390, клавиатура 3290, разъём питания 3290, аккумулятор 2890, матрица 3190, плата 4990, последствия жидкости 5090, Windows 1990, накопитель/перенос 2390, память 1890, BIOS 2890, данные 2890 рублей.

Для премиальной категории: охлаждение 2890, аккумулятор с отклейкой 3590, клавиатура/topcase 4390, USB-C/MagSafe 3990, плата/цепи питания 4990, macOS/данные 2490 рублей.

Все ремонтные суммы «от», только работа. Срочная диагностика 500 рублей отдельно. Не пересчитывать эти цены по данным конкурентов и не добавлять собственную стоимость запчастей.

Перед фактической публикацией владелец прайса должен сверить эти значения. На сайте это не превращается в надпись «тарифы не проверены»: публичная редакция уже содержит нормальные условия расчёта.

Не включены в страницу: промоценники из ранних блоков, скидка за заявку, дополнительная гарантия за отзыв, рассрочка, возврат с денежной компенсацией, количество мастерских и универсальное обещание ремонта за час.

## 5. Медиаплан

Требуются реальные материалы Ленремонта. Сначала использовать доступные изображения компании со страницы услуги или предоставленные владельцем. Не создавать синтетического «сотрудника Ленремонта», «реальную мастерскую» и «отремонтированный заказ», выдавая их за документальную съёмку.

Alt уточнять по фактическому кадру: нельзя приписывать ему невидимые действия. Один внешний кадр лаборатории можно повторно использовать в карточке формата с другим кропом. Изображение для курьера можно заменить нейтральной предметной фотографией упакованного ноутбука и соответствующим alt, если документальной передачи нет; не подделывать фотографическое доказательство.

### Технические требования к фото

- Контентные фото локальны, WebP/AVIF, без base64 и внешних hotlink.
- Hero: источник около 1600 px по ширине и мобильный вариант около 720 px.
- Остальные крупные кадры около 1400 px, карточки около 640 px.
- Это целевые размеры экспорта, а не требование искусственно увеличивать маленький оригинал.
- Явные width/height, srcset/sizes при нескольких вариантах.
- Целевой вес hero до 250 КБ при достаточном качестве; остальных кадров до 180 КБ, карточек до 90 КБ.
- Не растягивать лица и не обрезать основное оборудование.
- Нет встроенных в фото кнопок, цен, рейтингов и отзывов.
- Видео для понимания страницы не требуется.

Отсутствие подключения формы не является поводом перепроектировать всю страницу или показывать надпись «демо». Это также не разрешение показывать ложный успех. Телефон и ссылки на каналы общения предусмотрены как самостоятельные действия.
