# Блок времени ремонта

Добавлен 10 октября 2026 года по запросу пользователя. Сроки взяты из открытых
прайсов конкурентов Санкт-Петербурга; это ориентиры, а не подтверждённые сроки
Ленремонта. На странице это указано под прайсом. Цены проекта сохранены.

В `src/data/laptop-service.json` каждая строка `prices.tables` теперь содержит
`[работа, цена, ориентир времени]`. Прайсы и карточки симптомов продолжают брать
первые два значения. Компонент `Prices.astro` выводит время в третьей колонке прайса; на мобильном — под названием работы. Отдельная секция сроков удалена.

## Источники

- N: [Ноутбук·Профи](https://noutprofi.com/prices/). Доступен текст поискового индекса; прямое открытие не удалось.
- S: [Сервис 136 — Lenovo](https://service-136.ru/remont-lenovo).
- R: [reSale — ремонт после залития](https://recomspb.ru/remont-noutbukov/remont-posle-zalitija/). Доступен текст поискового индекса.
- L: [Прайс Lenovo](https://spb.lenovoservicecenter.ru/price/). Доступен текст поискового индекса; прямое открытие вернуло 502.
- A: [Apple-SC — прайс MacBook](https://spb.apple-ruscentr.ru/price).
- H: [Help4Apple — MacBook](https://help4a.ru/remont-macbook/).
- M: [SCMobile — MacBook](https://scmobile.ru/remont-i-chistka-noutbukov/remont-macbook/).

Диапазоны нельзя трактовать как среднее по рынку. Они различаются у сервисов и
моделей. Для комбинированных работ время переноса не включено в указанное время
установки. Диагностика, доставка и ожидание деталей согласуются отдельно. Для
премиальных ультрабуков использованы ориентиры MacBook с явным условием уточнения
по модели; отдельных подтверждённых сроков для всех ультрабуков нет.
