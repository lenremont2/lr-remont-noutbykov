# Объединение неисправностей в lr-symptoms

13 октября 2026 года отдельный lr-laptop-failures убран с главной страницы. Сетка lr-symptoms содержит девять карточек с уникальными дочерними адресами. Связь по slug, а не по позиции массива или пути изображения.

Добавлены страницы:

- /remont-cd-dvd-privoda-noutbuka.htm
- /remont-klaviatury-noutbuka.htm
- /remont-razemov-noutbuka.htm

Остальные адреса сохранены. Тексты восьми неисправностей перенесены в причины соответствующих страниц в src/data/service-pages.json. Предупреждение о жидкости сохранено. Заключение со ссылкой на сравнение сервисов находится под общей сеткой. Отдельный компонент, SCSS и массив laptop-failures удалены.

Восемь сгенерированных иллюстраций переиспользованы в карточках и подготовлены из исходных PNG в размере 768 × 512 px. Карточка «Не заряжается» сохраняет свою иллюстрацию. Промпты: 17_GENERATED_FAILURE_IMAGES.md. Фотографии иллюстративные, не реальные заказы.

Клавиатура и разъём зарядки используют утверждённый прайс. Для CD/DVD-привода цена не задана: карточка сообщает о бесплатной диагностике, страница объясняет согласование стоимости. Прайс зарядки не применяется к разъёму наушников: это отдельно указано в FAQ.

Дополнительные безопасные рекомендации адаптированы из официальных материалов:

- [Dell: клавиатура ноутбука](https://www.dell.com/support/contents/en-us/article/product-support/self-support-knowledgebase/mouse-keyboard-touchpad/laptop-keyboard-not-working).
- [Dell: неисправности оптических приводов](https://www.dell.com/support/kbdoc/en-us/000126039/troubleshooting-cd-dvd-or-blu-ray-drive-problems).

Проверки: npm run quality; node --test tests/*.test.mjs; наличие девяти уникальных карточек, отсутствие lr-laptop-failures, рабочие дочерние маршруты и отсутствие пустого прайса для CD/DVD-привода.
