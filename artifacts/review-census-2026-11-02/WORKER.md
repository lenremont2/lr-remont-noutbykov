# Задание работнику: одна карточка

Работать только с URL, назначенным координатором. Выход — `tasks/<taskId>/result.json`, фото — в этой же папке `photos/`. Сайт и соседние результаты не менять. Пользователь разрешил всестороннее публичное исследование всей сети РФ без API-ключей.

Проверить принадлежность сети по официальному сайту, телефону и адресу. Просмотреть доступные страницы/scroll до конца, раскрыть свёрнутые тексты, найти ноутбук/ноут/нетбук/ультрабук/MacBook/макбук и бренды в контексте ремонта, чистки, диагностики. Все оценки и даты. Не считать первую страницу всей выдачей. Не обходить CAPTCHA/авторизацию; фиксировать ограничения. Поисковый индекс — частичный источник. Не выдумывать точные счётчики по поисковым фрагментам.

Если наблюдаемый конец одной сортировки даёт меньше заявленного числа отзывов, проверить остальные доступные сортировки до их конца. Объединять по стабильным ID/точным текстам, фиксировать уникальные записи и пересечения; конец одной ограниченной сортировки не означает конец доступного корпуса. Не спрашивать разрешение на эту часть уже согласованного исследования.

Для фото доказать связь с конкретной карточкой, отличить отзыв от ответа компании/аватара/галереи. Скачать доступный оригинальный публичный файл, посмотреть, сохранить описание. Непроверенное вложение не помечать визуально проверенным. Ограничить цитирование: в итоговых данных краткие пересказы, точные ссылки; исходный полный текст при необходимости хранить только как локальное рабочее свидетельство.

Проверять не только `<img>`: у Zoon и других площадок вложения бывают CSS `background-image`, `data-src` и контейнерами фотопросмотрщика. Ноль IMG не доказывает отсутствие фото. Аватары и общую галерею отделять по фактическому контейнеру отзыва/ответа.

Для дедупликации подходящих отзывов сохранять `evidence.normalizedTextSha256`: SHA256 UTF-8 основного полного текста без автора/даты, ответа компании, UI и повторённого сокращённого превью. Нормализация: `text.normalize('NFKC').toLowerCase().replace(/[^\p{L}\p{N}]+/gu,' ').trim()`. Указать `normalizedTextAlgorithm: 'NFKC-lowercase-Unicode-words-v1'`. Если полный текст недоступен, hash не выдумывать. Совпадение hash — повод для сверки, не автоматическое доказательство независимости/личности.

JSON: `{taskId,platform,url,branch,city,networkEvidence,coverage:{status:'complete'|'partial'|'blocked',reportedTotal:null|number,examinedCount:null|number,endpointObserved:boolean,method,stopReason},reviews:[{author,date,rating:null|number,summary,reviewUrl,topic,photos:[{sourceUrl,localPath:null|string,attachment:'review'|'company_reply'|'avatar'|'gallery',bindingVerified:boolean,visuallyVerified:boolean,description}],evidence}],discoveredSources:[{platform,url,address,city}],notes:[]}`. `complete` только если проверен конец выдачи и полные тексты; иначе partial/blocked. При совпадении адресов старую и новую карточку не склеивать.

Проверять отдельные разделы площадок: у Zoon отклонённые отзывы, у Yell фильтр «Все источники», у 2ГИС неподтверждённые отзывы. Импорты и перепечатки отмечать с реальными ссылками на первоисточники, когда они опубликованы; не придумывать источник по сходному имени. Исследовательские артефакты будут опубликованы в GitHub по указанию пользователя. Не сохранять аккаунт браузера, cookies, ключи, токены и лишнюю оболочку пользовательского интерфейса; только публичные свидетельства исследования.

Наблюдение 2ГИС: в карточке Маршала Жукова текст группы не срабатывал, а клик по видимому родительскому переключателю `._wrckby` открыл106 неподтверждённых с «Загрузить ещё»50+50+6. Это пример, не гарантированный селектор: сначала осмотреть свой DOM/AX и видимый родительский элемент. Не объявлять раздел недоступным после одного неэффективного клика по тексту.

Неизвестные автор, дата или оценка записываются `null`, без выдуманных значений. Пограничные темы можно сохранить отдельно в `candidateReviews` с автором, датой, ссылкой, пересказом и `reason`, не добавляя в подтверждённые `reviews`. Если текст ссылается на фото, но доступного вложения нет, сохранить пояснение в `evidence.photoNote` и явный статус `evidence.photoCandidateStatus: 'mentioned_but_unavailable'`; координатор экспортирует это отдельно от найденных фото. Просто заметка об исключённом видеопостере не является таким фото-кандидатом.

Проверять не только ключевые слова: у отзывов с неопределённым устройством просмотреть привязанные миниатюры/вложения и уточняющий ответ компании. Очевидный ноутбук на фото при неясном тексте сохранить кандидатом с указанием, чего не хватает для подтверждения ремонта. Явно описанные покупки холодильников, сантехнику и другую нетематическую технику не подменять ноутбуками из общей галереи.

«(закрыта)» рядом с названием станции метро (например, Парк Победы/Фрунзенская) не означает закрытие мастерской. Проверять реальный статус организации в Обзоре; сохранять расхождения источников, не выводить закрытие филиала из статуса метро.
